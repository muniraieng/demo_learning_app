1. Yeh Screen Kya Karta Hai?

Login Screen user ko email aur password enter karne deta hai. Agar credentials sahi hain toh user Course Dashboard pe chala jata hai.

[Login Screen Image]
Email field, Password field, Login button
Welcome Back header with school icon

2. Files Involved

  • lib/presentation/screens/login_screen.dart — UI dikhata hai
  • lib/presentation/viewmodels/login_viewmodel.dart — State manage karta hai (GetX)
  • lib/domain/usecases/login_usecase.dart — Business logic
  • lib/data/repositories/auth_repository_impl.dart — Data handle karta hai
  • lib/core/storage/secure_token_storage.dart — Token save karta hai
  • lib/core/utils/input_validators.dart — Email/password validation

3. Complete Flow (Step by Step)

Step 1: User app kholta hai │ ▼ Step 2: main.dart me _RootGate check karta hai │ "Kya SecureStorage me token hai?" │ ├── Token hai → CourseDashboardScreen pe jao │ └── Token nahi hai → LoginScreen dikhao │ ▼ Step 3: User email + password enter karta hai │ TextFormField onChanged pe value set hoti hai │ controller.email.value = email │ controller.password.value = password │ ▼ Step 4: User "Login" button dabata hai │ Form validate hota hai (InputValidators) │ Email regex check, Password min 6 chars │ ▼ Step 5: controller.login() call hota hai │ isLoading.value = true (button loading me badal jata hai) │ ▼ Step 6: LoginUseCase call hota hai │ → AuthRepository.login(email, password) │ → AuthRepositoryImpl check karta hai │ email == 'test@demo.com' && password == 'demo123' │ ├── Sahi hain: │ → Token save hota hai SecureStorage me │ → (null, token) return hota hai │ → isLoading.value = false │ → Get.offAll(() => CourseDashboardScreen()) │ └── Galat hain: → (AuthFailure, null) return hota hai → error.value = AuthFailure → UI pe red text dikhta hai → isLoading.value = false

5. MVVM Pattern Kya Hai?

  • Model: AuthRepositoryImpl — Data source
  • ViewModel: LoginViewModel — State + Logic (GetX)
  • View: LoginScreen — Sirf UI, koi logic nahi

View ko Model ka pata nahi hota. ViewModel beech me hai.

6. GetX Kaise Use Ho Raha Hai?

  • .obs — Reactive variable (auto-update UI)
  • Obx() — Widget ko reactive banata hai
  • GetView<LoginViewModel> — Controller auto-milta hai
  • Get.offAll() — Navigate + purane screens remove
  • Get.put() — Dependency inject karta hai
