1. Yeh Screen Kya Karta Hai?

Dashboard Screen saari courses ki list dikhta hai. Har course ka title, instructor, lesson count aur progress bar hota hai. User kisi bhi course pe tap karke uske details dekh sakta hai. AppBar me logout button bhi hai.

3. Complete Flow (Step by Step)

Step 1: Screen khulta hai │ GetView apna controller leta hai │ ▼ Step 2: controller.load() call hota hai │ state = DashboardState.loading │ UI pe CircularProgressIndicator dikhta hai │ ▼ Step 3: GetCoursesUseCase call hota hai │ → CourseRepository.getCourses() │ ▼ Step 4: Repository check karta hai — Internet hai? │ ├── ONLINE: │ → RemoteDataSource JSON asset se data load karta hai │ → LocalDataSource Drift DB me cache karta hai │ → (null, courses) return karta hai │ └── OFFLINE: → Drift DB se cached data read karta hai → Cache hai? → (null, cachedCourses) return → Cache nahi? → (CacheFailure, null) return │ ▼ Step 5: Result ke hisaab se state set hota hai │ ├── Success + data hai → DashboardState.success │ → ListView me CourseCards dikhte hain │ ├── Success + data nahi → DashboardState.empty │ → "No courses available." message │ └── Error → DashboardState.error → Error message + Retry button

4. States Kya Hain?

ViewModel ke paas 5 states hain:

initial loading success empty error
initial → App just started, kuch load nahi hua loading → Data load ho raha hai (spinner dikhta hai) success → Data mil gaya, courses dikhao empty → Data nahi mila (no courses) error → Kuch gadbad hui (show error + retry)

5. Offline-First Kaise Kaam Karta Hai?

ONLINE (Internet hai): JSON Asset ──▶ RemoteDataSource ──▶ Repository │ ▼ Drift DB (cache) │ ▼ UI (courses) OFFLINE (Internet nahi hai): Drift DB ──▶ LocalDataSource ──▶ Repository ──▶ UI (courses) LESSON COMPLETE (Offline me bhi): User tap "Mark complete" │ ▼ Drift DB me update │ ▼ Progress recalculate (done/total * 100) │ ▼ UI update

7. Pull-to-Refresh

User neeche pull karta hai toh RefreshIndicator trigger hota hai:

RefreshIndicator └─ onRefresh: controller.refresh() └─ state = initial └─ courses reset to first 20 └─ load() dobara call

7.5 Lazy Loading (20 rows at a time)

Dashboard list lazy loading use karti hai — ek baar me sirf 20 courses dikhta hai. 50 courses me se pehle 20, phir 40, phir 50.

Step 1: Screen load → getCourses() se 50 courses aati hain │ courses = first 20 rows ▼ Step 2: User scroll karta hai neeche │ scrollController listener trigger │ pixels >= maxScrollExtent - 200 ▼ Step 3: controller.loadMore() │ isLoadingMore = true │ List ke bottom pe chhota CENTERED spinner dikhta hai │ await Future.delayed(600ms) — simulate network ▼ Step 4: Agli 20 rows append │ courses.assignAll(allCourses.take(+20)) │ isLoadingMore = false ▼ Step 5: hasMore == false hone tak repeat (20 → 40 → 50)
allCourses = 50 (full data, ek baar load) courses = visible slice (pehle 20, phir 40, phir 50) hasMore = courses.length < allCourses.length isLoadingMore = bottom spinner ka switch pageSize = 20

Bottom spinner ka code ListView.builder me extra last row hoti hai jo sirf tab dikhti hai jab isLoadingMore true ho:

if (i >= controller.courses.length) { return Center( child: SizedBox(width: 24.w, height: 24.h, child: CircularProgressIndicator(strokeWidth: 2.5)), ); }

8. Logout Kaise Kaam Karta Hai?

AppBar me logout icon hai. Tap karne pe:

IconButton (logout icon) └─ Get.find().deleteToken() └─ Get.offAll(() => LoginScreen())
