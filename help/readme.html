Simple Overview

Yeh app ek Learning Dashboard hai jahan user courses dekh sakta hai, lessons complete kar sakta hai, aur progress track hota hai. App offline-first hai — internet na ho tab bhi data dikhta hai.

Tech Stack

┌──────────────────┬─────────────────────────────────────────┐ │ Layer │ Technology │ ├──────────────────┼─────────────────────────────────────────┤ │ State Management │ GetX (Login, Dashboard) │ │ │ + Riverpod Notifier (Detail) │ │ Local Database │ Drift (SQLite) │ │ Networking │ Dio + dio_smart_retry │ │ Security │ flutter_secure_storage │ │ Background Sync │ workmanager │ │ Responsive UI │ flutter_screenutil │ └──────────────────┴─────────────────────────────────────────┘

Architecture: CLEAN + MVVM

┌─────────────────────────────────────────────────────┐ │ PRESENTATION │ │ Screens → ViewModels → Widgets │ │ (LoginScreen, CourseDashboardScreen, │ │ CourseDetailScreen) │ └──────────────────────┬──────────────────────────────┘ │ calls ┌──────────────────────▼──────────────────────────────┐ │ DOMAIN │ │ Entities (Course, Lesson) │ │ Repository Interfaces (abstract) │ │ UseCases (Login, GetCourses, GetDetail, MarkDone) │ └──────────────────────┬──────────────────────────────┘ │ implements ┌──────────────────────▼──────────────────────────────┐ │ DATA │ │ Repository Implementations │ │ DataSources (Remote = JSON asset, Local = Drift) │ │ Models (CourseModel, LessonModel) │ └─────────────────────────────────────────────────────┘

Dependency Rule: Outer layer inner layer ko call karti hai, inner layer ko outer layer ka pata nahi hota.

App Flow

App Start │ ▼ ┌─────────────┐ │ _RootGate │ ← SecureStorage me token hai? └──────┬──────┘ │ ┌───┴───┐ │ │ ▼ ▼ Login Dashboard Screen (token hai toh) │ │ Login success ▼ Dashboard ──tap course──▶ Detail Screen ▲ │ │ │ Mark lesson complete └──────────────────────────┘

Screens

  • GetX Login Screen — User email/password enter karta hai. Success pe Dashboard pe navigate.
  • GetX Course Dashboard Screen — Saari courses ki list. Pull-to-refresh. Har course pe progress bar. Lazy loading: 20 rows at a time, neeche chhota centered spinner jab next 20 load ho rahi hoon.
  • Riverpod Course Detail Screen — Ek course ke saare lessons. Lesson complete karne pe progress update.

Offline Kaise Kaam Karta Hai?

1. Online: Data JSON asset se load → Drift DB me cache → UI pe show 2. Offline: Drift DB se data read → UI pe show 3. Lesson complete: Drift DB me save → Progress recalculate

Lazy Loading Flow (Dashboard)

courses.json me 50 courses (AI / Python / React Native) │ ▼ Dashboard load → pehle 20 rows show │ ▼ User scroll to bottom ──▶ loadMore() │ └─▶ bottom CENTERED spinner (isLoadingMore) │ └─▶ +20 rows append ▼ 20 → 40 → 50 tak repeat, phir hasMore = false

Detail: help/course_dashboard_screen.html section 7.5. Code: course_dashboard_viewmodel.dart (pageSize=20, loadMore), course_dashboard_screen.dart (bottom loader row).
